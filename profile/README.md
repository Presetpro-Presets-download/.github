## 🧠 Overview

PresetPro is a large preset library for Lightroom and Camera Raw, organised by genre — portrait, wedding, landscape, lifestyle — with each pack built around a consistent tonal and colour direction. The product family is positioned as a lightroom preset library toolset for Windows workflows.

Presetpro Presets works as a preset pack on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe Lightroom Classic.

| Feature | Description |

## Additional Information for Windows Users

The preset pack registers itself in Adobe Lightroom Classic, Adobe Camera Raw during installation, so the host version matters more than the Windows build: update the host application before adding Presetpro Presets.

Presets are plain files, so Presetpro Presets can be copied between machines without a reinstall: the folder structure inside the archive matches the one the host application expects.
